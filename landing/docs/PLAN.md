# Документация проекта «Статический лендинг» (КТ2)

## Часть 1. Выбор референса и планирование

### Задание 1.1. Выбор референса
- **Тематика лендинга:** «TaskFlow» — сервис для планирования задач и личной продуктивности.
- **Источник:** Референс макета найден на Behance по запросу *«landing page task manager»* и сохранен в папку `docs/reference.png`.

---

### Задание 1.2. Список секций лендинга
1. **Header** — логотип, навигационные ссылки (Главная, Возможности, Тарифы, Контакты) и кнопка «Войти».
2. **Hero** — главный заголовок, краткое описание преимуществ, кнопка CTA «Попробовать бесплатно» и карточка с примером списка задач.
3. **Features** — блок ключевых возможностей (сетка из 3 карточек с использованием CSS Grid).
4. **Pricing** — карточки с 3 тарифами (Базовый, Продвинутый, Команда).
5. **Footer** — копирайт, ссылки на разделы и контакты.

---

### Задание 1.3. Цветовая палитра и шрифты
- **Фон страницы:** `#0f172a` (темно-синий)
- **Фон карточек:** `#1e293b`
- **Основной акцентный цвет:** `#2563eb` (синий)
- **Цвет заголовков и текста:** `#f8fafc` (светлый) и `#94a3b8` (серый)
- **Шрифт:** системный шрифт без засечек (Inter / sans-serif)
